KURULUM — Firebase CLI GEREKMEZ

1) Firebase Console:
   Ayarlar → Hizmet hesapları → Yeni özel anahtar oluştur.
   İndirilen JSON dosyasını aç ve tamamını kopyala.

2) Vercel:
   Project → Settings → Environment Variables
   Name:
   FIREBASE_SERVICE_ACCOUNT_JSON

   Value:
   Firebase'den indirdiğin JSON'un TAMAMI.

   Production, Preview ve Development seçeneklerini işaretle.

3) GitHub:
   Bu paketteki index.html, vercel.json, package.json ve api klasörünü
   mevcut projenin köküne koy.

4) Vercel otomatik deploy eder.

Firebase CLI, Node kurulumu veya Firebase Functions deploy işlemi gerekmez.
